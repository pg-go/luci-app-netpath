# NetPath 使用说明

NetPath 是装在 OpenWrt 路由器上的实时网络仪表盘，只读，只有给设备改名
这一个写操作。装好后退出 LuCI 再重新登录，登录后第一个页面就是它，
菜单入口是 `admin/dashboard`。

下图是它在一台真实路由器上的样子，图里的数字是截图那一刻的例子，
不是固定值；图里部分客户端名字已由机主打码。

![NetPath 仪表盘：健康条、网络路径图和底部汇总](screenshots/dashboard.png)

## 1. 打开方式

- 在浏览器打开路由器 LuCI，登录后直接就是仪表盘。
- 如果你的主题没有把它设为登录后首页，从菜单进 `admin/dashboard`。
- 刚装完或刚升级完，要先退出再重新登录，否则看不到新页面。

## 2. 顶部：健康条

最上面一行是结论，先看它，再看细节：

- **一切正常**：6 项检查全过，分别是上行链路、CPU、内存、Wi-Fi、
  信号、存储。
- 每一项都是一句话结论加数字，例如截图里是：上行 191 kbit/s 下行、
  81.8 kbit/s 上行、经 lan1、1G 链路；CPU 2%、负载 0.14、4 核、64°C；
  内存可用 78%（727 MiB / 930 MiB）；Wi-Fi 2 个已启用、2 个 SSID 正在
  广播；信号全部高于 -75 dBm；存储已用 3%。
- 哪一项出问题，它就会变色并写出原因，点那一项会直接打开它对应的
  内容，例如信号弱的客户端详情，或者弱信号客户端列表。

## 3. 中间：网络路径图

这是仪表盘最主要的一张图，从左到右就是数据实际走的路，点任意一个
方框都会打开它的详情抽屉：

- **互联网**：上层网关，例如截图里的网关和 DNS，以及上行接口、
  链路速率（截图里是 lan1、1G FD）。
- **此接入点**：本机，例如截图里的机型、内网地址和已运行时间。
- **射频分支**：2.4 GHz 和 5 GHz 各一张卡，写着 Wi-Fi 代际、信道、
  频宽和实时流量，例如截图里 2.4 GHz 是信道 1、20 MHz，5 GHz 是
  信道 36、160 MHz。
- **SSID 与客户端**：每个 SSID 下面是它的客户端，每台设备一个方框，
  写着名字和信号强度（dBm，数字越接近 0 越好，-50 dBm 左右算很好，
  -68 dBm 左右已经偏弱）。SSID 方框里还写着该 SSID 的客户端数，
  例如截图里 2.4 GHz 有 3 台、5 GHz 有 7 台。
- **有线分支**：下面是网口，例如截图里的 lan3（2 台设备）和 lan4
  （1 台设备），口方框写着设备数和口流量，口下面每个设备一个方框，
  写着名字和链路速率（例如 1 Gbit/s）。
- **连接线**：方框之间的线就是连接关系。线上有流动的点，说明这条
  线此刻有数据在走；线是静止的，说明此刻没有达到流动门槛，或者是
  共享口的线，口流量分不到单个设备，只能看口总量。

## 4. 底部：汇总

图下面一行是四个总数，一眼看全网：

- **客户端**：总数和分布，例如截图里共 13 台：3 台在 2.4 GHz、
  7 台在 5 GHz、3 台有线。
- **当前流量**：上下行实时速率和走的上行接口。
- **最繁忙射频**：哪个频段占 Wi-Fi 流量最多，例如截图里是 5 GHz、
  占 77%。
- **最弱信号**：信号最差的那台设备和它的信号值，例如截图里是
  -68 dBm，先从这台查起。

## 5. 客户端名字从哪来，怎么改名

客户端名字按这个顺序取，取到哪个用哪个：你手动改的别名、反向 DNS、
mDNS、DHCP 提示、WPS 设备名、厂商名；随机 MAC 的设备会显示为
“私有设备”，后面跟 MAC 尾段。

改名方法：点开一台设备的详情，在里面改名保存。名字只写进
`/etc/config/netpath`，最多 512 条，不会改动 Wi-Fi 配置，也不会
把 Wi-Fi 密码、密钥写进任何地方。反向 DNS 那一项是单独的权限组，
没开那个组就不会用反向 DNS 取名。

## 6. 右上角：实时与自定义

- **实时**：页面按固定节奏刷新，不用手动刷新浏览器。
- **自定义**：点右上角的自定义，可以拖动瓷砖调顺序、改宽度、
  隐藏不需要的瓷砖，布局按屏幕尺寸分别保存，改乱了可以恢复默认。
  自定义只改你这个浏览器的显示，不改路由器配置。

## 7. 防火墙概览

网络路径图之外，还有一个防火墙概览页，入口在
“网络 → 防火墙 → 概览”：

- 从互联网能进来什么、哪个区域能到哪个区域、哪些关了或被忽略了、
  哪些属于高风险情况。
- 每一项都链到能改它的 LuCI 页面，点过去就能改，不用自己去找。
- 这个页面只读展示，改动还是在原来那个 LuCI 页面里做。

## 8. 常见问题

- **页面不动、数字不更新**：先确认浏览器没有断网、路由器还在运行，
  再刷新一次页面；实时刷新只在页面打开时跑，切到后台会停。
- **某台设备名字不对或显示私有设备**：先在详情里手动改名；随机 MAC
  的设备本身不提供固定名字，改名后下次用同一个随机地址还会认得，
  换了新随机地址就要再改一次。
- **信号弱**：先看底部“最弱信号”那台，再看它在路径图里挂在哪个
  SSID、信号是多少，靠近一点、换到 5 GHz 或换信道后再看。
- **有线设备只看到口总量、看不到单台流量**：这是正常的，交换机后面
  挂了多台设备的共享口，口流量分不到单个设备，只有独占一个口的
  设备才能看到它自己的流量。
- **装完看不到仪表盘**：退出 LuCI 再重新登录一次；如果还是没有，
  按安装说明检查包是不是装上了（25.12 用 `apk info luci-app-netpath`，
  24.10 用 `opkg list-installed | grep luci-app-netpath`）。

## 关于这张截图

这张图是真实设备截图，不是演示数据，图里部分客户端名字已打码。
如果这份说明要公开发布，建议换成演示模式（`--demo`）下截的图，
演示模式会把 MAC、地址、SSID 和客户端名都换成文档用的假值，
再公开发就不会带真实设备信息。
